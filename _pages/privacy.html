Privacy Policy

Last updated: June 20, 2026

This website is a personal, static blog. I value your privacy and believe in data minimization. Below is a transparent disclosure of the technical data handled when you visit.

// hosting & server logs

This site is hosted on GitHub Pages (GitHub, Inc.). When you visit, GitHub automatically collects standard web server logs — your IP address, browser type and OS, and the date/time and page of your visit. GitHub uses this for security diagnostics and operational safety. I have no direct access to these logs and do not use them to identify or track anyone. See the GitHub Privacy Statement.

// cookies & tracking

This website does not use tracking cookies, marketing cookies, or pixels, and no third-party analytics (e.g. Google Analytics).

// data collection

No databases, registration, contact forms, or comments. I do not collect, store, buy, sell, or share any personal data from visitors.
