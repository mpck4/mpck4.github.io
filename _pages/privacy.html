Privacy Policy

Last Updated: June 20, 2026

This website is a personal, static blog. I value your privacy and believe in data minimization. Below is a transparent disclosure of the technical data handled when you visit this site.

1. Hosting and Server Logs

This website is hosted using GitHub Pages, a service provided by GitHub, Inc. When you visit this site, GitHub automatically collects and stores standard web server logs.

These logs include:

  • Your Internet Protocol (IP) address
  • Your browser type and operating system
  • The date, time, and page of your visit

Why this is collected: GitHub uses this data for security diagnostics, system maintenance, and to ensure the operational safety of its servers. Under certain regulations (like the GDPR), an IP address is considered personal data. I do not have direct access to these logs, nor do I use them to identify or track individuals.

For more details on how GitHub handles this information, please review the GitHub Privacy Statement.

2. Cookies and Tracking

This website does not use tracking cookies, marketing cookies, or tracking pixels. I do not use third-party analytics tools (such as Google Analytics) to monitor your behavior.

3. Data Collection by the Owner

I do not use databases, user registration systems, contact forms, or comment sections. As the owner of this website, I do not actively collect, store, buy, sell, or share any personal data from visitors.

4. External Links

This blog may contain links to external websites. If you click a link to an external site, please be aware that I have no control over their content or privacy practices. I encourage you to read the privacy policies of any site you visit.

5. Contact Information

If you have any questions about this minimalist privacy policy, you can reach out via a contact in the about me section.
